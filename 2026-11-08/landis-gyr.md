## 卡片正文（约360字）

Landis+Gyr是北美智能电表双寡头之一，Berg Insight统计其装机份额约32%，仅次于Itron的35%。公司2026年4月以2.15亿美元卖掉低毛利EMEA业务，转型聚焦美洲+亚太：卖Revelo智能电表，更卖软件与服务——软件约占持续收入25%，在手订单39亿美元、约3.3倍年收入。FY2025（截至2026-03-31）持续收入11.66亿美元、仅增4.2%，调整后EBITDA利润率14.4%；FY2026收入指引反降，增长要等FY2027–2028。利润质量有瑕疵：两年减值约3亿美元，商誉仍占权益69%；上半财年利润大增含4,680万美元关税退款。估值不便宜：约69.5美元对应FY2025持续市盈率约49倍、自算FY2026预期约28倍，EV/EBITDA约12倍，与更大、现金流更强的Itron相当。结论：**(b)公司优秀但等待更合理价格**；回落至约45–50瑞郎，或FY2027放量且利润率站稳16%以上，再重新评估。

## 1. 如何赚钱（普通人能听懂）

电力公司要知道每家每户用了多少电、哪里停电、哪里负荷过重，过去靠人工抄表。现在Landis+Gyr卖的是“一套数电表的系统”：

1. **硬件——智能电表与传感器（Connected Platforms，H1 FY2026收入3.64亿美元，占73%）**：Revelo等电表装在用户家门口，带通信模块与边缘计算，能远程读数、断/复电、监测电压与停电。按项目向电力公司批量销售，收入随大客户部署节奏大幅波动——一个大项目开工收入就冲高、完工就回落。
2. **软件与服务（Grid Intelligence，H1 FY2026收入1.38亿美元，占27%；公司口径软件及软件赋能服务约占FY2025持续经营收入25%，约2.9亿美元）**：电表数据管理、负荷预测、停电分析、计费等软件，以及运维服务。这部分毛利率结构性高于硬件，是公司要转型的方向；在手订单中43%与软件及软件赋能服务相关。
3. **收费方式**：硬件一次性项目销售 + 软件许可/订阅与服务费。客户是受监管的电力、燃气、水务公司，采购周期长（招标—试点—分批部署常以年计）、切换成本高（换一家供应商意味着换全网通信协议与后台系统），但也意味着单个大客户的去留对收入影响很大。

客户与地域（持续经营口径）：FY2025美洲10.40亿美元（占89%）、亚太1.26亿美元（占11%）。美国是绝对主力；2026上半财年半年报披露存在单一大客户（金额与占比在本次可获得的文本中未完整显示，见“证据缺口”），集中度风险真实存在。

## 2. 护城河证据与反面证据

**支持“候选龙头→准龙头”的证据：**
- **规模与装机份额**：Berg Insight（经ResearchAndMarkets 2025年北美智能电表报告转载）：北美智能电表装机份额Itron 35%、Landis+Gyr 32%、Aclara 21%，其余约12%为Honeywell、Sensus等；网络端点份额Itron 64%、Landis+Gyr 25%（来源[8]）。公司自称服务3,500多家公用事业（年报称“2,000多家”与“3,500+”两种口径并存，本报告取其低值表述）、1.8亿+联网智能设备。
- **在手订单**：2026-03-31承诺订单（committed backlog）38.93亿美元；2026-09-30为37.22亿美元，10月又获一家美国大型投资者所有制公用事业5.09亿美元订单（来源[4]）。订单/收入约3.3倍，锁定未来数年部署。
- **技术转向高毛利**：Revelo平台收入占比上升，Q4 FY2025调整后毛利率36.7%、Q2 FY2026达创纪录38.0%，H1 FY2026调整后毛利率37.7%（同比+370基点）。2026-09-30与Thales合作将SGP.32 eSIM植入Revelo/Surent平台，面向北美。
- **认证与可持续标签**：EcoVadis铂金（公司自称全球前1%），对参与公用事业招标有加分，但不是定价权证据。

**反面证据（护城河并不深）：**
- **北美市场已近饱和**：Berg Insight预计北美智能电表渗透率2024年82%→2030年91%，装机仅从1.524亿增至1.809亿（CAGR 2.9%），年出货量预计从2024年1,840万台降至2030年1,200万台；未来主要是“第二波换表”（占出货量近75%），是替换周期而非增量 rollout（来源[8]）。这意味着硬件量价都难有爆发，增长要靠软件与服务。
- **竞争者同等强大且更大**：Itron收入是其2倍、调整后EBITDA利润率15.8%、自由现金流3.83亿美元（见§7）；Siemens Smart Infrastructure收入230亿欧元、利润率18.3%，其电网软件（Gridscale X）可与Landis+Gyr正面竞争；Aclara、Honeywell、Sensus及欧洲的Kamstrup（未上市）都在同一市场。公司从未在年报中披露可验证的全球市占率排名，本报告不采信“全球第一”之类的自称。
- **低价出售EMEA**：EMEA业务FY2024收入约6亿美元、FY2025收入7.51亿美元，企业价值仅2.15亿美元（约0.3倍销售额），说明该资产盈利质量低、或买方议价极强；出售虽提升了报表利润率，却也放弃了欧洲这一仍有 rollout 空间的市场与地域分散。
- **客户自研/技术替代**：大型公用事业可自建或选用开放标准（Wi-SUN、蜂窝/eSIM）降低锁定；若通信标准进一步开放，硬件将更趋商品化，溢价只能来自软件——而软件收入占比25%，转型未完成。

**判断**：在北美智能电表硬件+通信领域是**真实的双寡头之一**，可称细分龙头；但护城河是“装机+认证+长周期客户关系”，不是网络效应或专利垄断，评级时不给垄断溢价。

## 4. 增长拆解（销量 / 涨价 / 并购 / 汇率 / 周期）

- **FY2023大增（总收入+16.7%）**：主因供应链恢复、交付前期积压订单（pent-up demand），是**周期性补库存**，非持续增速；FY2024随即回落−10.5%（恒定汇率），公司明确称“FY2023积压需求实现不可持续”。
- **FY2025持续经营+4.2%**：美洲+7.8%（Revelo需求+日本业务），亚太−18.8%（大项目时点）；恒定汇率+3.8%，汇率影响仅+0.4个百分点。**无并购贡献**（期内无重大收购披露），增长基本来自销量/项目执行与产品结构（高毛利Revelo与软件占比提升），非涨价——公司未披露价格/销量拆分，本报告不猜测涨价幅度。
- **FY2026指引下滑**：收入10.85–11.15亿美元（中点11.0亿，低于FY2025的11.66亿），公司称一个大客户部署完工、下一个大部署要到Q4 FY2026才放量，期间约有6,000万美元收入缺口（公司原指引口径）。H1 FY2026收入−6.3%、订单 intake 仅3.37亿美元（book-to-bill 0.7倍），证实青黄不接；10月5.09亿美元大单是转折信号，但收入确认在FY2027及以后。
- **中长期指引**：截至FY2028，收入中个位数CAGR、调整后EBITDA增速约为收入增速的2倍（公司2026-05-07公告）。这是**公司预期，不是承诺**，且以FY2026低基数为起点。

## 5. 资本配置（研发 / 扩产 / 并购 / 分红 / 回购）

- **研发**：FY2025研发支出9,280万美元（占持续收入8.0%），低于FY2024持续口径的1.095亿美元；H1 FY2026调整后研发4,070万美元（占收入8.1%）。研发强度在同业中不算高，但公司称Revelo与软件是研发重点。未披露资本化研发比例，本报告不将其费用化/资本化作调整。
- **扩产/资本开支**：资产轻模式，PP&E资本开支仅占收入2.0–2.7%（FY2025 3,850万美元、H1 FY2026 1,370万美元），生产以外包/轻资产为主，扩产不是资本开支重点。
- **并购/出售**：期内无重大收购；**出售是主线**：2025-09-29宣布、2026-04-08完成出售EMEA给AURELIUS，企业价值2.15亿美元，涉及5个生产基地、约2,700–2,800名员工；此前已退出EV充电业务。出售所得明确用于回购。
- **分红**：拟派CHF 1.20/股（2026-06-26股东大会提议，较上年CHF 1.15增4.3%），按56.90 CHF计股息率约2.1%，全部来自法定资本公积、免瑞士预扣税（公司披露）。FY2025全年向股东返还约7,000万美元（含分红与回购）。
- **回购**：2025-10月启动、规模上限1.75亿美元的回购，**已于2026-10月完成**：共回购2,870,387股、总代价1.424亿瑞郎，截至2026-10-27库存股2,890,894股（10.0%）。这是一次性返还出售所得，**不可视为经常性回购**；完成后净负债率从0.9倍升至1.5倍（公司口径）。
- **关联交易**：本次核查的年报摘要与半年报中未发现重大关联交易披露；未作深入核查，不作结论。

## 6. 三大最重要风险及传导机制

1. **项目青黄不接 + 大客户集中 → 收入断层**。收入高度依赖少数大型公用事业部署的时点：一个项目完工、下一个未放量，FY2026收入即指引下滑；H1订单book-to-bill仅0.7倍。若10月5.09亿美元订单的部署再延迟，或某大客户推迟招标/削减资本开支，收入与经营杠杆将双向放大下滑，调整后EBITDA利润率指引15–16%也难兑现。跟踪：季度订单 intake、book-to-bill、在手订单中软件占比。
2. **北美换表周期见顶 + 硬件商品化 → 量价双压**。北美渗透率已超82%，年出货量预计下滑；Itron、Aclara、Sensus及Siemens等均可供应同类产品，招标价竞争激烈。若软件收入占比不能持续提升（FY2025约25%），公司将困在低毛利硬件周期里，毛利率与估值倍数同时承压。跟踪：软件及软件赋能服务收入占比、调整后毛利率、Revelo收入占比。
3. **关税/供应链与商誉减值 → 利润一次性蒸发**。FY2024关税已影响3月出货时点；H1 FY2026的4,680万美元关税退款反向证明关税敞口之大，且该退款不可持续。更根本的是商誉7.62亿美元（占权益69%）：过去两年已减值1.11亿（FY2024）+约2亿（EMEA），若美洲业务增长不及预期或折现率上升，新的减值将直接吞噬全年净利润。跟踪：商誉减值测试披露、实际税率、净负债/EBITDA。

次要风险：美国上市推进不及预期（估值重估落空）、瑞郎/美元汇率（财报美元、股价瑞郎）、库存与应收随项目波动。

## 8. 估值

**方法选择**：以 **EV/调整后EBITDA 为主、P/E与自由现金流收益率为辅**，不用DCF作主估值。原因：①利润受商誉减值、终止经营、关税退款等一次性因素反复扭曲，GAAP P/E失真（FY2025持续经营P/E约49倍、总口径为负）；②公司是项目制硬件+软件混合体，EBITDA更能反映经营现金利润；③自由现金流波动大（FY2022为负），单年FCF收益率参考性弱。DCF对终值与折现率极敏感，在此仅作情景交叉验证，不单独给目标价。

**当前估值（自算，2026-11-06）**：
- 股价56.90 CHF ÷ 0.8189 = **约69.5美元**。
- 流通股约26,018,050股（已发行28,908,944 − 库存2,890,894，2026-10-27）→ 市值约**18.08亿美元**（按已发行股计为20.08亿美元，本报告估值用流通股口径并注明）。
- EV = 市值18.08亿 + 2026-09-30净负债2.581亿 = **约20.66亿美元**（若用2026-03-31净负债1.989亿则为20.07亿）。
- EV / FY2025调整后EBITDA（1.675亿）≈ **12.3倍**；EV / LTM调整后EBITDA（自算1.722亿）≈ **12.0倍**；EV / FY2026E调整后EBITDA（指引中点：收入11.0亿×利润率15.5%=1.705亿）≈ **12.1倍**。
- P/E：FY2025持续经营EPS 1.43美元 → **约48.6倍**；自算FY2026E：营业利润≈1.705亿−折旧摊销约0.55亿=1.16亿，扣利息约0.25亿、按30%税率计净利润约0.63亿，流通股26.0百万股计EPS约2.44美元 → **约28.5倍**（假设见下，属自算估计，非公司指引）。
- 自由现金流收益率：FY2025自算FCF 0.598亿 / 市值18.08亿 ≈ **3.3%**；H1 FY2026自算FCF 0.603亿不可年化（含关税退款与营运资本利好）。
- 股息率约2.1%。
- 历史比较：公司3年股价约−17%（easybank，口径为截至2026-11-06的3年表现），当前价接近其52周高位区间，历史EV/EBITDA无可验证的长期中枢可引（新口径仅两年），本报告不编造“历史平均倍数”。

**可比**：Itron 2025年调整后EBITDA 3.74亿美元、市值约44亿美元，EV/EBITDA约11–12倍（视净负债口径），GAAP市盈率约15倍、自由现金流收益率约8–9%——**同倍数下Itron的盈利质量与现金流明显更好**。Siemens整体市盈率不具可比性，不引用。

### 估值三情景（FY2028，3年视角；终点为截至2029-03-31的财年）

假设：起点FY2025持续收入11.662亿美元；净负债假设维持约2.0亿美元；流通股26.0百万股；汇率0.8189 CHF/USD。倍数取EV/调整后EBITDA。

**合理价值区间**：约 **43–110 CHF**，中枢在基准情景附近（约80 CHF），但区间极宽，反映利润率扩张与倍数均未被证实。**当前价56.90 CHF处于区间下半部、而非底部**：它已隐含了接近基准情景的约一半涨幅，却未留出执行不及预期的安全边际。若按悲观情景，当前价仍有约25%下行空间；若按基准情景，3年隐含回报约12%/年——但这要求收入5% CAGR与利润率从14.4%扩至17.0%同时兑现，而FY2026收入本身还在下滑。**因此本报告不把基准情景的80 CHF当作“目标价”**，只作为“执行完美时值多少”的上限参考。

**什么价格会改变判断**：若股价回落至 **45–50 CHF**（对应EV/调整后EBITDA约10倍、FY2026E市盈率约22–24倍、股息率约2.5%），且订单与毛利率未恶化，则可由(b)上调至(a)重新评估；若涨至75 CHF以上而无FY2027部署放量的实证，则估值理由减弱。

## 9. 结论与复查条件

**结论：(b) 公司优秀但等待更合理价格。**

核心理由：①北美智能电表双寡头地位与37亿美元订单簿真实，Revelo+软件转型方向正确，调整后毛利率已创纪录；②但FY2026收入指引下滑、H1订单book-to-bill仅0.7倍，增长兑现至少要等到FY2027；③利润质量受减值史（FY2024商誉1.11亿、EMEA约2亿）与H1关税退款4,680万美元拖累，税后资本回报仅约4–5%；④估值约28倍自算FY2026E市盈率、12倍EV/EBITDA，与更强更大的Itron相当，没有折价。

**什么会改变判断**：
- 上调至(a)：股价≤45–50 CHF，或FY2027收入恢复中个位数增长且调整后EBITDA利润率≥16%、软件收入占比继续提升。
- 下调至(c)/(d)：季度订单连续两季book-to-bill <0.8倍、10月5.09亿美元订单部署延迟、再现大额商誉减值、净负债/EBITDA持续>2倍，或美国上市出现重大不利变化。

**跟踪指标（2–3个）**：
1. 季度订单 intake 与 book-to-bill、在手订单（目标：恢复至≥1.0倍）；
2. 调整后毛利率与软件及软件赋能服务收入占比（目标：毛利率维持≥37%、软件占比向30%靠近）；
3. 自算自由现金流（OCF−PP&E）与净负债/调整后EBITDA（目标：FCF/收入≥5%、杠杆回落至≤1.2倍）。

**逻辑失效条件**：若北美第二波换表量价齐跌且Itron/Aclara以低价抢走核心大客户续约，或Revelo平台出现重大质量/交付问题，则“双寡头+软件转型”逻辑失效。

**主要潜在损失及不确定性**：悲观情景隐含股价约43 CHF，较现价下行约25%；若叠加商誉减值与项目延迟，损失可能更大。不确定性：美国上市时间与形式未定、关税政策、瑞郎/美元汇率、单一大客户集中度（具体占比未核查到，见缺口）。

## 证据缺口（诚实说明）

1. **股价为第三方聚合报价**：未取得SIX交易所官方收盘文件；easybank与Global Banking & Finance一致显示56.90 CHF，但52周高点在不同聚合源有59.20与64.80 CHF两个版本，本报告未采用。
2. **5年财务口径断裂**：FY2021–FY2022归属净利润取自第三方聚合，FY2024公司口径自由现金流未核查到；新分部（Connected Platforms / Grid Intelligence）仅披露FY2025–H1 FY2026，无法给出5年分部利润表。
3. **H1 FY2026单一大客户占比**：半年报披露存在单一大客户，但本次可获得的文本截断，未核查到具体占比；未作猜测。
4. **关税退款的会计归属**：公司称调整后EBITDA剔除4,680万美元关税退款，但退款在营业利润/所得税中的完整影响未在本次核查的摘要中拆清；H1利润的“ underlying”水平因此只能定性判断，不宜精确调整。
5. **美国上市**：仅知“持续推进、保留瑞士上市”，无交易所、时间表、募资额披露；估值未计入任何上市溢价。
6. **市场份额**：Berg Insight数据经第三方转载，未取得原始报告；公司未披露可验证的全球份额，本报告仅称北美双寡头之一。

上述缺口影响估值的精确度，但不改变(b)的方向性结论；若缺口1–4在年报/季报中补齐且指向更差的基本面，结论应下调至(c)。
