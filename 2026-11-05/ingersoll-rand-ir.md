### ① 如何赚钱：普通人能听懂的版本

Ingersoll Rand卖的是工厂、医院、实验室和数据中心离不开的“气、液、粉流动”设备，通俗讲就是：**把空气压起来、把真空抽出来、把液体和粉末精确地送到该去的地方，并且长期负责维修保养。**

它收钱有三层：

1. **卖设备（一次性）：** 压缩机、真空泵、鼓风机、空气处理设备、动力工具与起重设备，以及精密泵、计量与配液系统。客户买一台可以用很多年。
2. **卖耗材与服务（ recurring，关键利润来源）：** 滤芯、润滑油、密封件、备件、维修、维保合同。公司2025年报原文披露：售后零部件、耗材与服务收入占总收入的**36.5%**。2026年Q3电话会转述亦称售后约占当季收入36%，同比中个位数增长。机器装机量越大，以后每年要换的耗材和要修的单子就越多——这是典型的“剃须刀+刀片”模式。
3. **卖长周期工程项目：** 例如2026年Q3披露的约1.95亿美元数据中心大型定制订单（engineered-to-order），收入主要按完工进度在2027年确认，订单会“ lumpiness（忽大忽小）”，不能按季度线性外推。

**两个业务分部（2025年收入口径）：**

| 分部 | 2025年收入 | 占总收入 | 是什么 |
|---|---|---|---|
| Industrial Technologies and Services（IT&S，工业技术与服务） | 6,056.4百万美元 | 79.2% | 压缩机、真空、鼓风机、空气处理、动力工具、起重设备；品牌包括 Ingersoll Rand、Gardner Denver、Nash、CompAir、Elmo Rietschle 等80多个品牌（公司自述为80+品牌；10-K另述IT&S旗下35个以上品牌，口径为不同层面的品牌计数，不宜直接相加） |
| Precision and Science Technologies（P&ST，精密与科学技术） | 1,594.5百万美元 | 20.8% | 生命科学、工业精密应用以及航空航天与国防用的精密液体、气体、空气、粉末处理技术；含2024年收购的ILC Dover生命科学平台 |
| 合计 | 7,650.9百万美元 | 100% | — |

**客户与场景：** 通用制造、食品饮料、生命科学/制药、能源、交通、化工、半导体洁净、数据中心基建等。2025年报摘要披露：**58%的收入来自美国以外的客户**，制造基地分布在德国、英国、中国、意大利、印度等地——这既是全球化优势，也是汇率与关税风险的来源（见第六节）。

**收费方式：** 设备为一次性销售（部分长周期项目按进度确认）；售后为零部件单次销售 + 服务合同/维保。公司不靠订阅制软件收费，不要把它当成SaaS公司来估值。

### ② 护城河证据＋反面证据（与2家直接竞争者比较）

**先纠正一个常见误读：Gardner Denver今天不是独立竞争者。** 现Ingersoll Rand Inc.正是2020年2月29日由旧Ingersoll-Rand plc的工业分部 spin-off 后与 Gardner Denver 合并（Reverse Morris Trust）而成的公司，合并后旧股东与Gardner Denver股东约各占50.1% / 49.9%。所以把“Gardner Denver”列为当下独立对手会重复计算；它的历史意义在于：**今天的IR = Gardner Denver的压缩机/真空血统 + 旧IR工业分部的品牌与渠道**，这也是其品牌众多、整合频繁的根源。下文比较用 Atlas Copco（上市可比）与 Kaeser（非上市家族企业）两家真正独立的对手。

#### 护城河证据（正方）

1. **售后密度与转换成本：** 36.5%的售后占比（2025年报）+ 全球服务网络，客户换供应商要重新认证空气洁净度（如制药、食品、半导体的无油Class 0要求）、重新培训维修团队、承担停机风险。Q3售后仍保持中个位数增长，说明在设备周期波动时仍有缓冲。
2. **调整后利润率长期处于行业上沿：** 2025年分部调整后EBITDA利润率：IT&S 28.9%（1,747.9 / 6,056.4）、P&ST 30.0%（478.0 / 1,594.5）；集团调整后EBITDA利润率27.4%。即使剔除Q3关税退款，集团调整后EBITDA利润率仍为26.7%（552 / 2,065）。这个水平不是靠一两个季度做出来的。
3. **现金流兑现能力：** 2025年自由现金流1,220.1百万美元，相当于调整后净利润的91.0%（1,220.1 / 1,340.7）；2024年为93.0%（1,247.6 / 1,341.6）。轻资本开支是关键：2025年资本开支仅占收入1.8%（135.6 / 7,650.9），公司2026年指引亦称资本开支约占销售额2%。
4. **订单先行指标在Q3明显回暖：** Q3订单2,345百万美元、book-to-bill 1.14倍（订单/收入），IT&S book-to-bill 1.17倍，P&ST 1.01倍；有机订单+18%。这比收入更能反映未来几个季度的交付。

#### 反面证据（反方，不可忽视）

1. **GAAP利润率并不如调整后数字光鲜：** 2025年GAAP营业利润率仅15.0%（1,144.6 / 7,650.9），远低于27.4%的调整后EBITDA利润率，差额主要来自无形资产摊销387.5百万美元、商誉及无形资产减值273.4百万美元、重组与并购相关费用等。调整后数字剔掉了并购的真实成本——而并购恰恰是这家公司的核心增长方式，不能只看调整后。
2. **并购纪律在ILC Dover上被证伪过一次：** 2024年6月以约23.25亿美元现金收购ILC Dover（2024年预期收入约4亿美元、调整后EBITDA利润率30%出头、收购倍数约17倍2024年预期调整后EBITDA），2025年Q2即计提商誉减值229.7百万美元 + 其他无形资产减值43.7百万美元（合计273.4百万美元），第三方转述的减值原因包括：高压解决方案（High Pressure Solutions）少数股权的长期预测下调、ILC Dover航空航天与国防业务某大客户业务减少、折现率上升与同行倍数收缩。公司随后又披露与保险公司等达成总计约425.1百万美元的ILC相关和解回收（2026年Q2收25.0百万美元、Q3收162.5百万美元、余款预计Q4收取）。回收是好事，但它恰恰证明当初交易存在需要事后索赔的问题。
3. **关税与成本传导慢：** 公司在2025年Q4披露IT&S调整后EBITDA利润率同比下降140个基点，主要原因是关税的稀释影响与为增长投入的商业费用；2026年Q3剔除关税退款后，集团调整后EBITDA仅同比+1%，IT&S剔除退款后利润率同比下降120个基点（至27.8%）。涨价要穿透在手订单（backlog）才能体现在收入里，存在滞后。
4. **周期性并未消失：** 2025年Q2两个分部有机收入均下滑（IT&S有机-3.8%、P&ST有机-1.6%，第三方转述的当季数据），2024年Q4 IT&S有机收入亦下滑。售后能缓冲，不能免疫。

### ③ 近5年财务：统一口径，现金流能否支撑利润

**口径说明：** 收入、GAAP营业利润、归属母公司净利润取公司财报/第三方财报聚合的GAAP口径；经营现金流（OCF）取公司现金流量表口径；自由现金流（FCF）= OCF − 资本开支（公司定义）。2024–2025年资本开支与FCF以公司新闻稿为准（2025年：135.6 / 1,220.1；2024年：149.1 / 1,247.6）。2021–2023年资本开支在本次检索中存在第三方聚合口径差异（继续经营口径 vs 含处置口径，差额约数千万美元），故主表只列OCF，FCF仅列2023–2025年且2023年标注为第三方聚合口径，不混入结论性计算。

**自算公式（全部写出）：**

- GAAP营业利润率 = GAAP营业利润 / 收入。例2025年：1,144.6 / 7,650.9 = 15.0%。
- 净利率 = 归属母公司净利润 / 收入。例2025年：581.4 / 7,650.9 = 7.6%。
- 收入复合增速（CAGR）=（期末 / 期初）^(1/年数) − 1。2021→2025年：(7,651 / 5,152)^(1/4) − 1 = 10.4%；2023→2025年：(7,651 / 6,876)^(1/2) − 1 = 5.5%。
- 自由现金流 = 经营现金流 − 资本开支。例2025年：1,355.7 − 135.6 = 1,220.1。
- FCF兑现率（相对调整后净利润）= FCF / 调整后净利润。2025年：1,220.1 / 1,340.7 = 91.0%；2024年：1,247.6 / 1,341.6 = 93.0%。
- 净债务 / 调整后EBITDA =（长期债务 + 短期债务 − 现金）/ 调整后EBITDA。2025年末：(4,783.3 + 1.4 − 1,248.8) / 2,093.8 = 1.69倍，与公司披露的1.7倍一致。
- 应收账款天数 = 应收账款 / 收入 × 365。2025年：1,518.0 / 7,650.9 × 365 = 72天（2024年：1,335.4 / 7,235.0 × 365 = 67天），延长5天，需关注但未到失控程度。
- 存货天数（按销售成本）= 存货 / 销售成本 × 365。2025年：1,172.9 / 4,314.6 × 365 = 99天（2024年：1,055.0 / 4,065.0 × 365 = 95天），延长4天。
- 商誉+无形资产占比 =（商誉8,484.1 + 其他无形资产4,240.3）/ 总资产18,297.2 = 69.5%；占股东权益（10,154.0）为125.3%。**这是资产负债表上最大的风险点：超过三分之二的资产是并购留下的商誉与无形资产，减值会直接冲击净资产与GAAP利润。**

**现金流能否支撑利润？——分两层看：**

- **调整后利润：能支撑。** 2024–2025年FCF连续两年在1,220–1,248百万美元，FCF/调整后净利润在91%–93%，且资本开支率仅约2%，说明调整后利润不是纸面利润。
- **GAAP利润：2025年被一次性项目扭曲，不能直接用GAAP净利润判断。** 2025年GAAP净利润从839百万美元骤降至581百万美元，但OCF仅从1,396.7降至1,355.7百万美元（-2.9%），FCF仅从1,247.6降至1,220.1百万美元（-2.2%）。差额主因是非现金减值273.4百万美元 + 权益法投资损失127.1百万美元（合计400.5百万美元），两者均不直接消耗当期现金，但反映了过去并购标的的价值缩水。
- **股权稀释：总体是缩股，不是扩股。** 2025年全年回购与分红合计返还股东1,050百万美元，其中Q4回购315百万美元 + 分红8百万美元；2026年Q3回购350百万美元 + 分红8百万美元；董事会还在Q3新批准增加20亿美元回购授权（第三方转述的电话会内容）。稀释平均股数从2024年的407.2百万股降至2025年的401.0百万股，2026年指引的股数约390.5百万股；股权激励费用2025年为53.0百万美元，相对回购规模（2025年库存股购买现金流出1,018.0百万美元）较小，稀释不是主要矛盾。
- **负债：可控但因并购而上升。** 长期债务从2023年末的2,693百万美元（第三方资产负债表聚合）跃升至2024年末的4,754.4百万美元（为ILC Dover等并购融资），2025年末为4,783.3百万美元；利息费用从2023年的157百万美元升至2025年的253.9百万美元。净债务/调整后EBITDA 1.7倍不算高，但利息负担已明显加重，未来再做20亿美元级并购将考验杠杆上限。

**资本回报（自算，口径需说明）：**

- GAAP净资产收益率（期末口径）= 归属母公司净利润 / 期末母公司股东权益。2025年：581.4 / 10,089.8 = 5.8%（2024年：838.6 / 10,179.0 = 8.2%），被减值压低，不宜单独作为回报率结论。
- 现金回报代理指标 = 调整后EBITDA /（股东权益 + 净债务）。2025年：2,093.8 /（10,154.0 + 3,535.9）= 15.3%；2024年：2,018.1 /（10,245.3 + 3,216.3）≈ 15.0%。这个口径剔除了摊销与减值的影响，更能反映经营性现金回报的稳定性，但它不是会计ROIC，不能与教科书ROIC直接比较。

### ④ 增长拆解：销量 / 涨价 / 并购 / 汇率 / 周期

**公司披露的拆分口径：** 报告收入增长 = 有机增长 + 汇率影响 + 并购影响（并购指收购后第一年内的被收购业务收入）。有机增长本身包含销量与涨价，但公司新闻稿通常不把“量”与“价”拆到小数点后一位披露，故下文只拆到公司披露的层级，不编造量价拆分。

**2025年Q4（可核对的完整拆分，公司新闻稿附表）：**

- 集团：总收入+10.2% = 有机+2.9% + 汇率+3.3% + 并购+4.0%；订单+8.5% = 有机+1.1% + 汇率+3.0% + 并购+4.4%。
- IT&S：收入+10.7% = 有机+2.7% + 汇率+3.3% + 并购+4.7%。
- P&ST：收入+8.1% = 有机+3.7% + 汇率+3.1% + 并购+1.3%。
- **解读：Q4的亮眼增长约三分之二来自汇率与并购，有机只有约3%，不能把Q4的10%当成内生增速。**

**2025年全年（缺口说明）：** 本次抓取的2025全年新闻稿摘要未完整披露全年的有机/汇率/并购三分拆（只披露了Q4附表），故本报告**不推算全年拆分**，只陈述总量：收入+5.7%（7,235.0 → 7,650.9），订单+9%（7,105.5 → 7,715.9百万美元）。任何声称“2025全年有机增长X%”的数字若无公司附表支撑，均属推测。

**2026年前三季度（可核对的片段）：**

- Q3 2026：收入+5.6%（1,955.0 → 2,064.9），公司口径有机约+4%，第三方转述拆分为并购约+1.4%、汇率约+0.3%（合计约5.7%，与5.6%存在四舍五入差异）；订单+21%，有机+18%，其中IT&S订单+25%（有机+22%），含约1.95亿美元数据中心大单。

- **周期判断：** 2025年Q2有机下滑、2026年Q3有机订单大涨，说明周期在底部徘徊后出现回暖迹象，但Q3订单中长周期大单占比高，收入确认要到2027年，不能把订单增速直接当成下季度收入增速。

**涨价传导：** 公司多次提到关税与通胀压力、涨价滞后于在手订单。2025年Q4 IT&S利润率下降、2026年Q3剔除退款后利润率下降，均指向“成本先涨、价格后到”。涨价不是没有，而是慢。

### ⑥ 3大最重要风险及传导机制

**风险1：并购与商誉减值风险（已发生过，传导最直接）**

- **机制：** 高价收购（ILC约17倍）→ 被收购业务的大客户流失 / 行业倍数收缩 / 折现率上升 → 商誉与无形资产减值（2025年273.4百万美元）+ 权益法投资损失（127.1百万美元）→ GAAP净利润与净资产同时缩水 → 市场质疑并购纪律 → 估值倍数下修；即使现金流未立即恶化，股价也会先跌。
- **放大器：** 商誉+无形资产占总资产69.5%、占权益125.3%，减值空间在账面上很大；未来若再做20亿美元级交易，杠杆（已1.7倍）与利息（已253.9百万美元）会进一步上升。
- **观察点：** 是否再出现单季超1亿美元的减值；ILC剩余回收款能否在Q4如期到账（公司称预计Q4收取余款）。

**风险2：工业周期 + 关税 + 汇率三重挤压（正在发生，传导滞后）**

- **机制：** 全球制造业资本开支放缓 → 设备订单与有机收入下滑（2025年Q2已有先例）→ 同时关税推高进口零部件与整机成本、汇率波动（58%非美收入）放大收入与利润的波动 → 涨价被在手订单锁定，无法立即传导 → 分部利润率下滑（2025年Q4 IT&S -140个基点；2026年Q3剔除退款后IT&S -120个基点）→ 调整后EBITDA增速被压至低个位数（Q3剔除退款后仅+1%）→ 指引下调或不及预期 → 倍数收缩。
- **关键细节：** Q3的关税退款（IEEPA，3,200万美元）是一次性收益，剔除后才是真实经营趋势；把含退款的28.3%利润率当成常态会高估。
- **观察点：** 剔除退款后的IT&S利润率能否重回29%以上；有机订单能否连续两个季度保持正增长。

**风险3：一次性收益掩盖真实趋势 + 长周期订单的 lumpiness（最容易误判）**

- **机制：** 2026年Q3 GAAP净利润669.9百万美元（同比+174%）很大程度上来自ILC和解回收的会计确认与关税退款，而非当季经营现金的同比例增长；同时约1.95亿美元数据中心订单的收入要到2027年才主要确认 → 投资者若按Q3 GAAP EPS（1.73美元）年化（×4 = 6.92美元）会严重高估 → Q4或2027年若回收款到账节奏变化、或大单确认不及预期，EPS会出现“断崖式”回落 → 市场以“业绩变脸”定价。
- **放大器：** 2026年全年自由现金流转换指引为100%以上（含ILC回收），剔除回收后仍为约95%——两者相差的5个百分点就是一次性因素的体量，读指引时必须区分。
- **观察点：** Q4是否披露ILC余款到账金额与2026全年FCF转换的剔除口径；2027年数据中心订单的收入确认进度。

*次要风险（未列入前三，但需知晓）：中国市场波动（2024年Q4曾拖累P&ST有机增长）、单一大客户依赖（ILC航空航天与国防业务已有先例）、供应链与关键零部件、网络安全与合规成本。*

### ⑦ 估值：方法选择、比较与三情景

**为什么选“调整后EPS市盈率 + EV/调整后EBITDA”双方法，而不用DCF为主？**

- IR的价值主要来自轻资本开支下的持续现金流与回购，DCF对永续增长率与折现率极其敏感，且商誉减值、一次性回收会让历史现金流序列失真，DCF的假精确度更高。
- 调整后EPS市盈率能直接对接公司指引（2026年调整后EPS 3.58–3.70美元），市场也按此定价；EV/调整后EBITDA能剔除资本结构与折旧摊销差异，便于与Atlas Copco等对手做跨公司比较。两者交叉验证，结论更稳。
- **但必须同时披露GAAP市盈率的失真：** 按2025年GAAP EPS 1.45美元计，市盈率高达58.0倍（84.17 / 1.45），这个数字反映的是减值年份的GAAP利润，不代表常态盈利能力，不能单独用于“贵/便宜”判断。

**当前倍数（自算，公式写出）：**

- 市值 = 391.122百万股 × 84.17美元 = 32,921百万美元（约329亿美元）。
- EV = 32,921 + 3,536（净债务）= 36,457百万美元（约365亿美元）。
- EV / 2025年收入 = 36,457 / 7,651 = 4.76倍。
- EV / 2025年调整后EBITDA = 36,457 / 2,094 = 17.4倍。
- 市盈率（2025年调整后）= 84.17 / 3.34 = 25.2倍。
- 市盈率（2026年指引中点，剔除退款）= 84.17 / 3.64 = 23.1倍（3.64 = (3.58 + 3.70) / 2）。
- EV / 2026年指引调整后EBITDA中点 = 36,457 / 2,160 = 16.9倍（2,160 = (2,130 + 2,190) / 2）。
- 自由现金流收益率（2025年）= 1,220 / 32,921 = 3.7%；FCF市盈率（按稀释股数401.0百万股计，FCF/股 = 1,220.1 / 401.0 = 3.04美元）= 84.17 / 3.04 = 27.7倍。两种分母（期末流通股 vs 平均稀释股）略有差异，结论方向一致：现金回报率约3.7%，不算便宜。

**可比与历史比较（口径差异必须说明）：**

- Atlas Copco：第三方聚合在2026-11-04附近的TTM市盈率约32–33倍（不同股份类别/ADR口径），高于IR的2026年指引调整后市盈率23.1倍；但Atlas用的是GAAP口径TTM市盈率，IR用的是调整后指引市盈率，两者不可直接比大小，只能说“IR在调整后口径下并不比Atlas贵”。
- 自身历史：**缺口：本次检索未取得经核对的IR过去5年市盈率/EV-EBITDA历史区间（第三方聚合的历史倍数口径不一），故不编造“历史均值X倍”作为锚点。** 替代的历史锚点是经营层面：2025年调整后EBITDA利润率27.4%低于2024年的27.9%，GAAP营业利润率从18.0%降至15.0%，说明当前利润率并非历史高点，估值不应按历史最高利润率外推。

**三情景（假设测算，不是收益承诺；两种方法交叉，取交集为合理价值区间）：**

| 情景 | 假设（调整后EPS × 市盈率） | 假设（EV/调整后EBITDA） | 合理价值（两种方法交集/平均方向） | 相对现价84.17美元的假设涨跌幅 |
|---|---|---|---|---|
| **悲观** | 2026–2027年调整后EPS约3.30美元 × 18倍 = 59.4美元 | EBITDA约2,050百万美元 × 14倍 = EV 28,700百万美元；减净债务3,536百万美元，除以约390.5百万股 = 64.4美元 | **约59–64美元** | -29% 至 -24% |
| **基准** | 指引中点3.64美元 × 23倍 = 83.7美元 | EBITDA中点2,160百万美元 × 17倍 = EV 36,720百万美元；减净债务后 / 390.5百万股 = 85.0美元 | **约84–85美元** | 约持平（-0.2% 至 +1.0%） |
| **乐观** | 调整后EPS约3.90美元 × 27倍 = 105.3美元 | EBITDA约2,350百万美元 × 19倍 = EV 44,650百万美元；减净债务后 / 390.5百万股 = 105.3美元 | **约105美元** | +25% |

**合理价值区间：约59–105美元，基准约84–85美元。** 区间很宽，恰恰说明当前信息下估值对“并购是否再减值、关税能否传导、数据中心大单能否按期确认”三个假设高度敏感——这不是模型无能，而是公司本身的不确定性。

**为什么不给精确目标价：** 上述两种方法在基准情景下恰好收敛于84–85美元，但悲观与乐观的跨度达46美元；给出一个精确到小数点后一位的“目标价”会伪装成精确，误导读者。本报告只给区间与触发条件。

### ⑧ 结论四选一

**选择：(b) 公司优秀但等待更合理价格。**

**核心理由（3条）：**

1. **优秀是真的：** 售后占比36.5%、调整后EBITDA利润率27%以上、自由现金流连续两年超12亿美元且兑现率超90%、资本开支率仅约2%、订单book-to-bill 1.14倍——这是一家现金流质量上乘的工业龙头候选者，不是周期故事股。
2. **价格已反映基准情景：** 现价84.17美元 ≈ 基准价值84–85美元，没有安全边际；若按悲观情景，下跌空间达24%–29%，而乐观情景的上涨空间（+25%）需要“有机增长持续回暖 + 无新增减值 + 数据中心大单按期确认”三者同时成立，赔率不对称。
3. **干净的证明还没交出来：** 2025年减值与2026年一次性回收、关税退款交织，Q3剔除退款后调整后EBITDA仅+1%，IT&S利润率仍在承压。等待不是怀疑公司，而是等待“剔除一次性因素后的利润率与有机增长”连续两个季度企稳的证据。

**什么价格或经营条件会改变判断：**

- **转向(a)可考虑买入：** ① 价格跌至约**75美元以下**（约较现价低11%，对应2026年指引调整后EPS约20.6倍、EV/调整后EBITDA约15倍，开始有安全边际）；若跌至约**65美元以下**（接近悲观区间上沿），则即使悲观假设也有缓冲。② 或经营上：连续两个季度有机收入与有机订单均为正、剔除退款后的集团调整后EBITDA利润率重回27.5%以上、且无新增大额减值——即使价格未跌至75美元，也可重新评估为(a)。
- **转向(c)继续观察：** 若Q4出现新增减值、或ILC余款未能如期收取、或2027年指引下调有机增长至接近零，则从(b)降级为(c)（问题从“价格”变为“逻辑待验证”）。
- **转向(d)暂时回避：** 若净债务/调整后EBITDA升至2.5倍以上、或连续两个季度剔除退款后的调整后EBITDA同比下滑、或再出现类似ILC规模的并购减值，则逻辑受损，应回避。

**2–3个跟踪指标（按重要性排序）：**

1. **有机订单与有机收入（剔除并购与汇率）+ 剔除IEEPA退款后的IT&S调整后EBITDA利润率。** 这是判断“周期回暖是否真实、涨价是否传导”的最干净指标。Q3基准：有机订单+18%、有机收入+4%、IT&S剔除退款后利润率27.8%。
2. **自由现金流转换率（剔除ILC回收口径）与净债务/调整后EBITDA。** 公司指引：含回收为100%以上、剔除回收后约95%；2025年末杠杆为1.7倍。若剔除口径的转换率跌破90%或杠杆升破2.0倍，需警惕。
3. **ILC Dover余款收取与新增减值。** Q4应披露余款（425.1百万美元总额 − 已收187.5百万美元 = 约237.6百万美元待收，按公司“Q2收25.0 + Q3收162.5 = 187.5”的口径自算）是否到账，以及有无新增减值计提。

**什么事实会使逻辑失效：**

- 售后占比从36.5%持续下滑至30%以下且自由现金流兑现率跌破85%，说明“剃须刀+刀片”模式被侵蚀；
- Atlas Copco或Kaeser等对手在无油/变频等关键产品线上取得代际领先，导致IR丢失大客户（类似ILC航空航天业务的大客户流失重演）；
- 再次发生超2亿美元的商誉减值，证明并购纪律未改善。

**主要潜在损失及不确定性：**

- **价格损失：** 悲观情景下约24%–29%的假设跌幅（至59–64美元区间）；若周期与关税同时恶化，跌幅可能超出该区间（本报告未设下限）。
- **时间损失：** 即使最终证明公司优秀，若在84美元附近买入而未来两年调整后EPS仅低个位数增长，持有期的机会成本可能高于指数。
- **不确定性清单：** ① 2025全年有机/汇率/并购拆分未完整披露；② 2021–2022年资本开支口径未以公司原文逐项核对；③ 研发费用单独金额未核对；④ Atlas Copco市盈率在不同股份类别/ADR口径下为28–33倍，跨市场比较存在口径误差；⑤ 2026年Q3后的净债务未以同一表格逐项核对，EV为约数；⑥ 本报告股价为第三方聚合价，非交易所官方价。以上缺口均不计入结论，读者不应将其视为已验证事实。
