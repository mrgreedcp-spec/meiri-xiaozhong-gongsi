# 每日小众公司

小众行业龙头投资研究日报：每天研究 10 家不太受大众关注、但具有竞争优势的细分行业龙头公司，通过年报理解其商业模式并判断投资价值，支撑 3—5 年视角的投资决策。

评级说明：(a) 值得深入研究 / 可考虑买入区间；(b) 关注、等待触发价；(c) 观望；(d) 回避或已无交易价值。结论以各期报告正文为准。
