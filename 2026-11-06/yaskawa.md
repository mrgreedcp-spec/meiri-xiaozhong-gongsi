## 二、如何赚钱：普通人能听懂的版本

**一句话：安川是给工厂造"手、胳膊和神经"的公司。**工厂要自动化，需要三样东西：让机器精准转动的电机、搬东西/焊接/组装的机械臂、指挥它们的控制器。安川三样都做，而且是少数能把"电机+控制器+机器人"成套卖的厂商。

### 2. 收费模式

- **卖硬件为主**：一次性销售伺服电机、驱动器、机器人本体及系统集成；另有维护、备件和软件服务，但**公司未披露经常性/服务收入占比**——这是本报告的一个信息缺口：无法判断收入中有多少是耗材、维保、软件订阅这类"细水长流"的钱。
- **项目制色彩重**：机器人业务有不少大型系统集成项目，收入确认与项目交付节奏挂钩，毛利率随项目结构波动大（见下文：上财年大型低附加值项目拉低了机器人利润）。
- **为什么选它研究**：伺服+机器人双赛道，且是全球"四大家族"（发那科、ABB、库卡、安川）之一；同时它正处在一个罕见的交叉点——股价半年腰斩、AI/半导体需求拉动订单创纪录、但机器人利润却在下滑、新ERP系统还出了生产事故。便宜是真便宜了，还是基本面真的变差了，值得拆开看。

## 三、护城河：证据与反面证据

### 正面证据（护城河确实存在）

1. **技术纵深：伺服是机器人的"心脏"，安川两者都做。** 自研伺服电机+控制器+机器人本体的垂直整合，使机器人与伺服的匹配、控制算法、能效可以协同优化。2025年6月发布的 **MOTOMAN NEXT** 平台是具体例证：机器人控制单元（RCU）+ 基于 NVIDIA Jetson Orin NX 的自主控制单元（ACU）、Linux + Docker 容器、预装无碰撞路径规划、力控与2D/3D/AI视觉（HALCON）功能模块，NEX系列负载7—35kg；新协作机器人NHC系列内置RGB-D"bodycam"。2026年10月28日披露的与丰田GAZOO Racing合作的AI弧焊系统（9月已在群马GR Kart工厂投用）能自主识别管架间隙与温度、自主决定焊接参数并焊后检验纠错——这是MOTOMAN NEXT从展品走向客户产线的第一个公开案例（但公司未披露合同金额、台数与量化效益，见反面证据）。
2. **百年积累与客户粘性**：1915年成立，伺服与机器人技术迭代了数十年；半导体设备、汽车产线的认证周期长、切换成本高，客户不会轻易换供应商。公司称其在i³-Mechatronics（集成、智能、创新）方案下与核心客户深度绑定。
3. **订单是最硬的领先证据**：2026年10月9日半年报说明会上，公司称第二季度（2026年6—8月）订单**同比+38%、环比+13%，创季度历史新高**；10月13日Q&A称"订单远超预期"，客户正为2027财年增产做准备，不少订单是2027财年交付的项目，尤其半导体相关；预计当前订单水平将持续到第三、第四季度。运动控制上半财年收入+21.7%（见第四节）与之呼应。
4. **半导体+数据中心是真实的顺风**：上半财年运动控制增长由半导体、电子元器件、机床需求及数据中心空调、油气用驱动器拉动；公司在2026年4月年报中亦称半导体市场下半年在AI投资带动下全球复苏。

### 反面证据（护城河正在被侵蚀，或至少不像宣传的那么宽）

1. **机器人利润率崩了，且不是行业共性问题**：机器人分部营业利润率从上上财年（截至2025年2月）的10.0%（237.5亿÷2,374亿）降至上财年的8.3%，再到本财年上半年的**5.0%**（59.7亿÷1,184亿）。同期发那科整体营业利润率21.4%且机器人业务仍是其最大收入来源（见第六节）。安川自己解释：大型低附加值项目占比高、欧洲重组费用约10亿日元、新ERP系统导致生产问题、半导体机器人增产尚未完全对冲。——**问题不在需求，而在产品结构与执行。**
2. **自己造成的生产事故**：2026年5月切换核心IT系统（S/4HANA）出现故障，导致工厂出货延迟、机会损失与固定成本上升；上半财年营业利润因此减少约40亿日元（公司Q&A口径）。一家以"精密控制"为卖点的公司，在自己的系统切换上失控，是执行力的负面信号；公司称影响在第二季度已基本消除，但下半年能否兑现15%（运动控制）/9%（机器人）的分部利润率指引，仍待验证。
3. **中国对手的追赶是结构性的，不是价格战传闻**：汇川技术（Inovance）2025年收入451.0亿人民币（+21.8%），2026年前三季度收入379.6亿人民币（+19.9%）；据第三方行业数据，2026年上半年汇川在中国通用伺服系统市占率35.2%、低压变频器20.6%，均为第一。安川的伺服基本盘在中国市场直面一个"更大、更快、更便宜且本土服务响应更快"的对手。公司年报亦承认中国市场竞争与盈利改善是持续课题。
4. **ABB的选择值得警惕**：ABB于2025年10月8日宣布将整个机器人业务以**53.75亿美元**企业价值出售给软银集团（此前计划为2026年分拆上市）。ABB机器人2024年收入约23亿美元且同比下滑，EBITDA利润率仅12.1%（第三方分析），远低于ABB集团平均水平。——**全球巨头之一选择退出机器人，说明这个行业的资本回报并不如"四大家族"光环暗示的那么好。**
5. **MOTOMAN NEXT尚未证明能赚钱**：公司未披露AI机器人销量、收入拆分或客户节省金额；丰田GR Kart案例未披露节拍、缺陷率、人工干预次数。2026年6月IR Day的Q&A亦承认，农业、医疗等新领域在Dash 35期间"不假设显著扩张"，规模仅"数百亿日元量级且不确定性高"。AI叙事目前是期权，不是利润。
6. **客户自研风险真实存在**：特斯拉等头部客户自研执行器/机器人供应链、半导体设备商对伺服的定制化要求提高，都是长期变量；本报告未找到安川披露前五大客户集中度的数字，**无法量化单一客户流失的影响**，列为缺口。

**小结**：护城河评级——**中等偏窄且正在受压**。伺服技术与客户认证是真壁垒；但机器人业务的盈利能力、成本控制与中国竞争三项，近两年都在走弱。不能仅凭"四大家族"之名认定其为龙头。

**自算要点**：
- 收入4年复合增速（2022→2026）：(5,421÷4,791)^(1/4)-1 ≈ **+3.1%/年**——增长乏力。

- 营业利润率从11%+的中枢跌至8.7%，且连续三年下滑（11.3%→9.3%→8.7%）。

**现金流质量判断**：
- 好的一面：OCF > 净利润，经营利润不是纸面富贵；资产负债表不危险（权益比率59.5%，净负债/权益约10%）。

## 八、三大最重要风险及传导机制

### 风险1：半导体/汽车资本开支周期反转（概率中高，影响最大）
- **机制**：安川收入高度依赖半导体设备、机床、汽车三大资本开支周期。半导体设备投资一旦放缓 → 伺服订单（运动控制占收入43.5%）率先下滑 → 高固定成本（5号工厂折旧+人工）使营业利润率加速下跌（经营杠杆）→ 存货（219天）减值风险上升 → FCF进一步恶化。
- **证据**：2025财年收入-6.6%、营业利润-24.3%就是上一轮周期下行的样子；Beta 2.59说明股价对市场波动极敏感。
- **当前信号**：订单创纪录是利好，但订单中有不少是2027财年交付项目，**订单≠收入**，且公司承认"收入（剔除汇率）未达预期"。

### 风险2：机器人业务结构性盈利能力无法恢复（概率中，影响深远）
- **机制**：大型低附加值系统项目占比高 + 欧洲重组 + 新工厂爬坡成本 → 机器人利润率长期低于10% → Dash 35的"利润翻倍"目标落空 → 市场对"AI机器人"叙事证伪 → 估值从20倍远期市盈率向15倍以下回归。
- **证据**：机器人利润率已连续三年下滑（10.0%→8.3%→上半财年5.0%）；公司自己称"要超过10%须提高5号工厂利用率并改善产品结构"，但未给出时间表；下半年指引要求机器人利润率9%，上半年仅5%，**下半年需环比大幅改善**。
- **传导**：若2027财年全年机器人利润率仍低于8%，Dash 35目标的可信度将基本丧失。

### 风险3：Dash 35战略投资（1,200亿日元）执行失败 + 日元/关税扰动（概率中，影响中等）
- **机制**：1,200亿日元战略投资（Physical AI并购/合作）若买贵或整合失败 → 商誉减值（目前商誉仅74亿，风险敞口在未来）+ FCF被吞噬 + 分红/回购空间压缩；同时美国关税政策（年报已点名"地缘政治与美国关税"）与日元升值会同时冲击收入与利润（2026财年美元贬值已拖累利润）。
- **证据**：公司历史上并购记录有限，缺乏大规模并购整合的公开成功案例可供验证；2026财年投资现金流出已达442亿日元。
- **次要风险**：ERP/系统切换类"自伤"再次发生；半导体机器人等高毛利产品增产不及预期；中国本土对手在伺服高端市场进一步突破。

## 九、估值：方法、比较与三情景

### 方法选择
- **主方法：市盈率（P/E）+ EV/EBITDA交叉验证**。安川是周期性制造企业，利润波动大，DCF对永续增长率与折现率极敏感，可靠性低；P/E直观且可与发那科、自身历史比较。FCF收益率作辅助（当前仅0.6%，无吸引力）。
- **为什么不用PB**：PB约2.0倍看似不高，但ROE仅7.7%，PB-ROE框架下2倍PB对应约15%的隐含ROE要求，**当前ROE远不达标**，PB不便宜。
- **可比**：发那科远期市盈率未在本报告核实精确值（未获取其2026年11月5日股价），不作数字比较；仅定性指出发那科21.4%的利润率应享有更高倍数，安川的合理倍数应**低于**发那科。

## 十、结论：(c) 继续观察（关键证据不足）

### 核心理由（四点）
1. **公司不差，但财务不优秀**：伺服+机器人技术底子与订单是真的（Q2订单创纪录、运动控制+21.7%），但营业利润率8.7%、ROE 7.7%、FCF仅59亿日元、存货219天——这是一家**正在消化扩产与系统事故成本、利润率处于谷底的周期制造商**，不是一家已证明能稳定赚取高回报的龙头。
2. **最关键的证据还没到**：机器人利润率能否从上半年的5.0%恢复到指引的下半年9%、全年营业利润能否达到575亿日元、ERP影响是否真正消除——这三个问题的答案都在**2027年1月三季报与2027年4月年报**里，现在下注等于为管理层的指引预付全款。
3. **Dash 35目标宏大但未经验证**：营业利润两年内从473亿翻倍至1,000亿日元，需要利润率从8.7%升至15.4%；而过去三年利润率一路下滑。1,200亿日元战略投资的标的、价格、整合计划均未披露，无法评估。
4. **估值无安全边际**：远期市盈率20.5倍、EV/EBITDA 15.2倍、FCF收益率0.6%，对应悲观情景仍有约26%下行空间。股价腰斩已反映部分悲观，但未反映"机器人利润率长期低于8%"的悲观。

### 什么会改变判断
- **升级为(b)（公司优秀但等待更合理价格）**：2027年1月三季报显示机器人分部利润率回升至8%以上、且公司确认ERP影响消除；或股价跌至**约3,200日元以下**（对应2027财年指引市盈率约17.5倍、悲观情景价值附近），则进入"值得等待的价格区"。
- **升级为(a)（可考虑买入）**：2027年4月年报确认全年营业利润≥575亿日元、机器人全年利润率≥9%、经营现金流恢复至600亿日元以上且FCF恢复至150亿日元以上，同时股价仍在4,000日元以下。
- **降级为(d)（暂时回避）**：三季报机器人利润率仍低于6%、或全年指引再度下调、或半导体订单出现环比大幅下滑、或Dash 35战略投资出现高价并购且无明确协同说明。

### 跟踪指标（2—3个，按优先级）
1. **机器人分部营业利润率（季度）**：目标下半年9%、全年≥8%；低于6%为失效信号。
2. **订单与收入的转化**：季度订单同比增速（Q2为+38%）及运动控制收入增速能否维持15%以上；订单高增但收入不跟进，说明生产/交付仍有瓶颈。
3. **自由现金流与存货**：季度FCF是否转正并回升、存货天数是否从219天回落至180天以下；存货不降，利润修复的可信度打折。

### 什么事实会使逻辑失效
- 若发那科、汇川等对手的机器人/伺服利润率同步大幅下滑，证明是行业性周期而非安川个体问题，则"安川执行差"的判断需修正。
- 若MOTOMAN NEXT在2027财年披露可验证的规模化收入（如单季度AI机器人收入超50亿日元）且毛利率高于传统机器人，则AI叙事从期权变为利润，估值框架需重估。
- 若公司宣布大额、高协同的并购且价格合理（如EV/EBITDA低于12倍），Dash 35目标的可信度上升。

### 主要潜在损失及不确定性
- **最大损失来源**：半导体周期反转 + 机器人利润率不恢复的双击，悲观情景价值约2,780日元，较现价下行约26%；若周期深度调整，跌破52周低点3,674日元后无明确技术支撑。
- **不确定性**：① 研发费用未披露，无法评估创新投入强度；② 服务/经常性收入占比未披露，收入质量未知；③ 前五大客户集中度未披露；④ 第三方对2023财年经营现金流口径冲突，该年现金流趋势无法核实；⑤ 股价为第三方聚合收盘价，非交易所官方价，估值计算以此为准，误差约±1%以内（多源一致）。
- **本报告不构成投资建议**；未假设用户可交易日本市场；未给出仓位比例。
